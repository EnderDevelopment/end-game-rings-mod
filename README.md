# End Game Rings Mod

Craftable end-game rings for Fabric 1.20.1

## Features

- **Aura Farming Ring**: A powerful ring that enhances farming abilities.
- **Thermotic Ring**: A ring that provides thermal protection and offensive capabilities.

## Requirements

- Minecraft 1.20.1
- Fabric Loader
- Fabric API
- Trinkets API
- GeckoLib

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/end-game-rings-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with Fabric Loader.

## Usage

1. Craft the rings using the appropriate recipes.
2. Equip the rings using the Trinkets API.
3. Enjoy the enhanced abilities provided by the rings.

The mod does not have a configuration file. All settings are hardcoded within the mod.
